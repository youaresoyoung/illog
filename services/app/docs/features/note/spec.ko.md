# 노트 에디터 기능 정의서

## 1. 개요

각 로그(Task)에 1:1로 연결되는 **리치 텍스트 노트**를 작성하고 자동 저장하는 기능입니다. Lexical 에디터를 기반으로 하며, 저장은 디바운스된 자동 저장 방식만 제공합니다(수동 저장 버튼 없음).

## 2. 목적 및 사용자 가치

- 로그 한 줄만으로는 담기 어려운 맥락·과정·결정 사항을 자유롭게 기록한다.
- 저장 행위를 의식하지 않고 작성에만 집중할 수 있게 한다.
- 작성된 노트는 AI 회고 생성의 입력값이 된다.

## 3. 용어 정의

| 용어           | 정의                                                                            |
| -------------- | ------------------------------------------------------------------------------- |
| 노트(Note)     | 로그에 종속된 리치 텍스트 본문. 로그당 최대 1개                                 |
| 자동 저장      | 편집 중단 후 일정 시간이 지나면 자동으로 저장하는 동작                          |
| 충돌(Conflict) | 클라이언트가 알고 있는 마지막 수정 시각보다 저장소의 수정 시각이 더 최신인 상태 |

## 4. 데이터 모델

테이블 `task_note` (`src/main/database/schema/note.ts`)

| 컬럼         | 타입 | 제약                                         |
| ------------ | ---- | -------------------------------------------- |
| `task_id`    | text | PK이자 `task.id` FK, `ON DELETE CASCADE`     |
| `content`    | text | 에디터 상태를 직렬화한 JSON 문자열           |
| `updated_at` | text | 저장 시각(밀리초 타임스탬프를 문자열로 보관) |

- `task_id`가 기본 키이므로 로그당 노트는 **최대 1개**다.
- 로그가 삭제되면 노트도 함께 삭제된다(CASCADE).

## 5. 기능 상세

| ID         | 기능                  | 설명                                                                                                            |
| ---------- | --------------------- | --------------------------------------------------------------------------------------------------------------- |
| FR-NOTE-01 | 노트 조회             | 로그 ID로 노트를 조회한다. 노트가 없으면 빈 값을 반환한다.                                                      |
| FR-NOTE-02 | 자동 저장             | 편집이 멈춘 뒤 **1초** 후 노트 본문을 저장한다. 노트가 없으면 새로 만들고, 있으면 덮어쓴다.                     |
| FR-NOTE-03 | 충돌 감지             | 저장 시 클라이언트가 보낸 마지막 수정 시각과 저장소의 수정 시각을 비교해, 저장소가 더 최신이면 덮어쓰지 않는다. |
| FR-NOTE-04 | 저장 순서 보장        | 연속된 저장 요청을 직렬 큐로 처리해 이전 요청이 나중 요청을 덮어쓰지 않게 한다.                                 |
| FR-NOTE-05 | 초기 내용 로딩        | 로그 상세 패널을 열면 저장된 노트를 에디터에 복원한다.                                                          |
| FR-NOTE-06 | 서식 편집             | 블록 서식과 텍스트 서식을 지원한다(5.1, 5.2 참조).                                                              |
| FR-NOTE-07 | 마크다운 단축 입력    | 마크다운 문법을 입력하면 대응하는 서식으로 즉시 변환한다.                                                       |
| FR-NOTE-08 | 실행 취소 / 다시 실행 | 편집 이력을 유지한다.                                                                                           |

### 5.1 블록 서식

툴바 드롭다운으로 선택한다.

`Normal(문단)` · `Heading 1~6` · `Numbered List` · `Bulleted List` · `Check List` · `Quote` · `Code Block`

- 이미 같은 블록 타입인 상태에서 다시 선택하면 일반 문단으로 되돌아간다(토글 동작).
- 코드 블록은 구문 강조를 지원한다.

### 5.2 텍스트 서식

툴바 버튼 및 선택 영역 위에 뜨는 플로팅 툴바로 적용한다.

`Bold` · `Italic` · `Underline` · `Strikethrough` · `Inline Code` · `Subscript` · `Superscript`

### 5.3 기타 편집 기능

| 기능        | 동작                                                                                                                  |
| ----------- | --------------------------------------------------------------------------------------------------------------------- |
| 링크        | 링크 삽입 시 URL 유효성을 검증하며, 유효하지 않은 문자열은 링크로 변환하지 않는다.                                    |
| 자동 링크   | 본문에 입력된 URL을 자동으로 링크로 인식한다.                                                                         |
| 체크리스트  | 체크 상태를 토글할 수 있다.                                                                                           |
| 들여쓰기    | Tab / Shift+Tab으로 목록 들여쓰기 단계를 조절한다.                                                                    |
| 플로팅 툴바 | 텍스트를 선택하면 선택 영역 위(공간이 없으면 아래)에 서식 툴바가 나타나며, 에디터 경계를 넘지 않도록 위치가 보정된다. |

## 6. 비즈니스 규칙

| ID         | 규칙                                                                                                                       |
| ---------- | -------------------------------------------------------------------------------------------------------------------------- |
| BR-NOTE-01 | 자동 저장 디바운스는 **1초**다.                                                                                            |
| BR-NOTE-02 | 저장 본문은 에디터 상태(JSON) 전체를 직렬화한 문자열이다. 평문이 아니다.                                                   |
| BR-NOTE-03 | 충돌이 감지되면 저장을 건너뛰고 저장소의 최신 저장 시각만 반환한다. 사용자 입력은 덮어쓰지 않으며 별도 병합도 하지 않는다. |
| BR-NOTE-04 | 저장 요청은 단일 직렬 큐를 통해 순차 처리된다.                                                                             |
| BR-NOTE-05 | 로그가 삭제되면 노트도 함께 삭제된다.                                                                                      |
| BR-NOTE-06 | 노트를 개별적으로 삭제하는 기능은 제공하지 않는다.                                                                         |

## 7. 화면 및 인터랙션

- 위치: 로그 상세 패널(`RightPanel`) 하단, AI 회고 영역 바로 위
- 구성: 상단 툴바(블록 서식 드롭다운 + 텍스트 서식 버튼) / 본문 편집 영역(최소 높이 400px)
- 빈 상태 안내 문구: `Start typing your notes here...`
- 로그를 전환하면 해당 로그의 노트가 다시 로딩된다.

## 8. 예외 및 오류 처리

| 상황               | 처리                                                                                        |
| ------------------ | ------------------------------------------------------------------------------------------- |
| 저장 실패          | 오류 토스트 표시 — `Note failed to save: <사용자 메시지>`                                   |
| 저장소 upsert 실패 | 오류를 상위로 전파해 토스트로 표시                                                          |
| 충돌 감지          | 오류가 아니라 정상 응답으로 처리(`conflict: true`). 사용자에게 별도 안내는 표시하지 않는다. |
| 에디터 내부 오류   | Lexical 에러 바운더리가 처리하며 콘솔에 기록한다.                                           |

## 9. 인터페이스 (IPC 채널)

| 채널                | 인자                                   | 반환                                                                    |
| ------------------- | -------------------------------------- | ----------------------------------------------------------------------- |
| `note.findByTaskId` | `taskId`                               | 노트 또는 빈 값                                                         |
| `note.autoSave`     | `taskId`, `content`, `clientUpdatedAt` | `{ note, savedAt, conflict: false }` 또는 `{ savedAt, conflict: true }` |

## 10. 현재 제한사항 및 향후 계획

- 충돌이 발생해도 사용자에게 알리지 않으며, 병합·비교 UI가 없다.
- 노트 저장 성공 여부를 보여주는 저장 상태 표시(예: "Saved")가 없다.
- 이미지·파일 첨부, 표, 수평선 노드를 지원하지 않는다.
- 노트 검색, 내보내기(마크다운/PDF)를 지원하지 않는다.
- 노트 자동 저장 이벤트(`note_auto_saved`)는 분석 이벤트 상수로 정의되어 있으나 실제로 전송되지 않는다.
