# 캘린더 뷰 기능 정의서

## 1. 개요

시작·종료 시각이 입력된 로그를 **시간 축 위의 블록**으로 배치해 보여주는 뷰입니다. Today 화면의 일간 캘린더와 주간 요약 화면의 7일 캘린더 두 가지 형태로 제공됩니다.

## 2. 목적 및 사용자 가치

- 하루/한 주의 시간이 실제로 어떻게 쪼개졌는지 목록이 아닌 시각적 배치로 확인한다.
- 비어 있는 시간대와 겹치는 작업을 즉시 알아본다.

## 3. 제공 형태

| 형태        | 위치                          | 열 수 | 현재 시각 표시              |
| ----------- | ----------------------------- | ----- | --------------------------- |
| 일간 캘린더 | Today 화면 (`/`)              | 1     | 항상 표시                   |
| 주간 캘린더 | 주간 요약 화면 (`/this-week`) | 7     | 오늘에 해당하는 열에만 표시 |

## 4. 기능 상세

| ID        | 기능                | 설명                                                                    |
| --------- | ------------------- | ----------------------------------------------------------------------- |
| FR-CAL-01 | 시간 그리드 렌더링  | 24시간 시간 축과 눈금을 표시한다.                                       |
| FR-CAL-02 | 로그 블록 배치      | 로그의 시작 시각과 소요 시간에 맞춰 블록의 세로 위치와 높이를 계산한다. |
| FR-CAL-03 | 자정 넘김 분할      | 여러 날에 걸친 로그를 날짜별 구간으로 나눠 각 날짜에 표시한다.          |
| FR-CAL-04 | 겹침 레이아웃       | 시간이 겹치는 로그들을 가로로 나눠 배치한다.                            |
| FR-CAL-05 | 색상 적용           | 로그의 작업 유형 색상을 블록 배경·테두리·글자 색에 적용한다.            |
| FR-CAL-06 | 블록 정보 표시      | 제목, 시간 범위, 유형·프로젝트 정보를 표시한다.                         |
| FR-CAL-07 | 현재 시각 표시      | 현재 시각 위치에 표시선을 그린다.                                       |
| FR-CAL-08 | 블록 클릭           | 블록을 클릭하면 해당 로그의 상세 패널이 열린다.                         |
| FR-CAL-09 | 요일 헤더 (주간)    | 요일 약어와 날짜를 표시하고, 오늘 열을 강조한다.                        |
| FR-CAL-10 | 빈 상태 안내 (일간) | 표시할 로그가 없으면 안내 문구를 현재 시각 근처에 표시한다.             |

## 5. 배치 규칙

### 5.1 표시 대상 필터

- **시작 시각과 종료 시각이 모두 있는 로그만** 표시한다. 한쪽이라도 없으면 캘린더에 나타나지 않는다.
- 해당 날짜 구간과 전혀 겹치지 않는 로그는 제외한다.

### 5.2 자정 넘김 로그 분할 (FR-CAL-03)

| 날짜              | 표시 구간                 |
| ----------------- | ------------------------- |
| 같은 날 시작·종료 | 시작 시각 → 종료 시각     |
| 시작일            | 시작 시각 → 자정          |
| 중간일            | 00:00 → 24:00 (하루 전체) |
| 종료일            | 00:00 → 종료 시각         |

### 5.3 크기 계산

| 항목           | 규칙                                          |
| -------------- | --------------------------------------------- |
| 세로 위치      | `(자정으로부터의 분 ÷ 60) × 시간당 높이`      |
| 블록 높이      | `(소요 분 ÷ 60) × 시간당 높이`, 최소 **22px** |
| 최소 소요 시간 | **15분** (그보다 짧아도 15분으로 계산)        |
| 정렬           | 시작 시각 오름차순                            |

### 5.4 겹침 처리 (FR-CAL-04)

1. **그룹화** — 시작 시각 순으로 훑으며, 현재 그룹의 마지막 종료 시각보다 먼저 시작하는 로그를 같은 그룹으로 묶는다.
2. **컬럼 배치** — 그룹 내에서 그리디 방식으로 컬럼을 배정한다. 기존 컬럼의 마지막 블록이 끝난 뒤에 시작하는 로그는 같은 컬럼에 이어 붙이고, 어느 컬럼에도 들어갈 수 없으면 새 컬럼을 만든다.
3. **폭 계산** — 그룹의 총 컬럼 수만큼 가로 폭을 균등 분할하고, 컬럼이 2개 이상이면 블록 사이에 간격을 둔다.

### 5.5 색상 규칙 (FR-CAL-05)

| 조건                            | 배경 / 테두리 / 글자                                         |
| ------------------------------- | ------------------------------------------------------------ |
| 작업 유형 색상 있음             | 해당 색상의 태그 배경 토큰 / 태그 텍스트 색 / 태그 텍스트 색 |
| 작업 유형 없음 또는 미매핑 색상 | 브랜드 3차 배경 / 브랜드 기본 테두리 / 기본 텍스트 색        |

지원 색상: `blue`, `green`, `yellow`, `purple`, `red`, `gray`

### 5.6 블록 텍스트 (FR-CAL-06)

| 요소 | 내용                                                | 조건                                |
| ---- | --------------------------------------------------- | ----------------------------------- |
| 제목 | 로그 제목                                           | 항상                                |
| 부제 | `HH:mm – HH:mm`                                     | 시작·종료 시각이 모두 있을 때       |
| 설명 | `<작업 유형명>` 또는 `<작업 유형명> · <프로젝트명>` | 작업 유형이 있을 때 (일간 뷰에서만) |

주간 뷰는 공간이 좁아 제목(11px)과 부제(10px)만 표시한다.

## 6. 비즈니스 규칙

| ID        | 규칙                                                                                  |
| --------- | ------------------------------------------------------------------------------------- |
| BR-CAL-01 | 시간이 입력되지 않은 로그는 캘린더에 표시되지 않는다.                                 |
| BR-CAL-02 | 소요 시간이 15분 미만이어도 15분 크기로 표시해 클릭 가능성을 보장한다.                |
| BR-CAL-03 | 겹치는 로그는 숨기지 않고 모두 가로로 나눠 표시한다.                                  |
| BR-CAL-04 | 주간 뷰의 주 시작 요일은 월요일이며, 주간 요약 화면의 주 기준을 그대로 따른다.        |
| BR-CAL-05 | 블록 색상은 작업 유형 색상만 반영한다. 프로젝트 색상이나 태그 색상은 사용하지 않는다. |
| BR-CAL-06 | 캘린더는 읽기 전용이다. 드래그로 시간을 옮기거나 늘릴 수 없다.                        |

## 7. 상태별 표시

| 상황                       | 표시 내용                                                                                          |
| -------------------------- | -------------------------------------------------------------------------------------------------- |
| 일간 뷰에 표시할 로그 없음 | `No time-tracked tasks for today. Add start & end times to see them here.` (현재 시각 아래에 표시) |
| 주간 뷰에 표시할 로그 없음 | 별도 안내 없이 빈 그리드만 표시                                                                    |

## 8. 관련 기능

- 로그 시간 입력: [`task`](../task/spec.ko.md)
- 일간 캘린더가 사용되는 화면: [`today`](../today/spec.ko.md)
- 주간 캘린더가 사용되는 화면: [`weekly-summary`](../weekly-summary/spec.ko.md)
- 유형 색상 정의: [`task-type`](../task-type/spec.ko.md)

## 9. 현재 제한사항 및 향후 계획

- 드래그·리사이즈로 시간을 조정할 수 없다(읽기 전용).
- 빈 시간대를 클릭해 새 로그를 만드는 기능이 없다.
- 월간 뷰가 없다.
- 표시 시간 범위를 좁힐 수 없다(항상 24시간 전체를 렌더링).
- 주간 뷰에는 빈 상태 안내 문구가 없다.
- 캘린더 스크롤 위치가 현재 시각으로 자동 이동하지 않는다.
