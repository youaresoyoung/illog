# AI Reflection — Feature Specification

## 1. Overview

Takes the note body as input and has **AI generate a reflective summary**. The result streams into the UI in real time and is persisted one-to-one with the task on completion. The feature is gated behind a paid plan.

## 2. Purpose and User Value

- Automatically distill the key points out of long work notes, reducing the effort of writing a retrospective.
- Stream the generation so the wait feels shorter.

## 3. Terminology

| Term       | Definition                                                                   |
| ---------- | ---------------------------------------------------------------------------- |
| Reflection | Summary text generated by AI from the note body                              |
| TextRank   | Algorithm that extracts important sentences from a sentence-similarity graph |
| Streaming  | Delivering generated text incrementally in chunks                            |

## 4. Data Model

Table `task_reflection` (`src/main/database/schema/taskReflection.ts`)

| Column               | Type | Constraints                                  |
| -------------------- | ---- | -------------------------------------------- |
| `id`                 | text | PK, auto-generated UUID                      |
| `task_id`            | text | UNIQUE, FK to `task.id`, `ON DELETE CASCADE` |
| `content`            | text | NOT NULL, generated reflection body          |
| `original_note_hash` | text | SHA-256 hash of the input note body          |
| `model_name`         | text | Name of the model used for generation        |
| `created_at`         | text | Creation timestamp                           |
| `updated_at`         | text | Update timestamp                             |

- Because `task_id` is UNIQUE, a task has **at most one** reflection.

## 5. Functional Requirements

| ID        | Feature                    | Description                                                                                   |
| --------- | -------------------------- | --------------------------------------------------------------------------------------------- |
| FR-AIR-01 | Generate (streaming)       | Generates a reflection from the note body, pushing text chunks to the UI as they arrive.      |
| FR-AIR-02 | Key-sentence preprocessing | Instead of sending the raw text, extracts key sentences via TextRank and uses those as input. |
| FR-AIR-03 | Persist result             | Saves the full body once streaming ends, overwriting any existing reflection (upsert).        |
| FR-AIR-04 | Read reflection            | Fetches the stored reflection by task ID.                                                     |
| FR-AIR-05 | Delete reflection          | Deletes the reflection by task ID.                                                            |
| FR-AIR-06 | Regeneration confirmation  | Shows an overwrite confirmation dialog before regenerating when a reflection already exists.  |
| FR-AIR-07 | Feature gating             | Rejects generation when the user's plan lacks the `ai.reflection` feature.                    |
| FR-AIR-08 | Listener cleanup           | Removes the stream event listener once generation ends.                                       |

### 5.1 Processing flow

```
Note body
  → Sentence splitting (sentences under 10 chars dropped)
  → Sentence similarity matrix
  → TextRank scoring
  → Top sentences extracted, reassembled in original order
  → Combined with the prompt template
  → Generation model invoked (streaming)
  → Chunks forwarded to the renderer
  → On completion, full body + source hash persisted
```

### 5.2 TextRank preprocessing parameters

| Parameter               | Value                                                                   |
| ----------------------- | ----------------------------------------------------------------------- |
| Damping factor          | 0.85                                                                    |
| Iterations              | 30                                                                      |
| Minimum sentence length | 10 characters                                                           |
| Sentences extracted     | `max(3, 30% of total sentences)`                                        |
| Exception               | When there are 3 or fewer sentences, all are used without preprocessing |

## 6. Business Rules

| ID        | Rule                                                                                                                     |
| --------- | ------------------------------------------------------------------------------------------------------------------------ |
| BR-AIR-01 | A task has at most one reflection; regeneration overwrites the existing one.                                             |
| BR-AIR-02 | The generate button is disabled when the note body is empty.                                                             |
| BR-AIR-03 | During generation the button is disabled and its label becomes `Generating...`.                                          |
| BR-AIR-04 | On plans where `ai.reflection` is disabled, the button reads `AI Reflection (<required> plan required)` and is disabled. |
| BR-AIR-05 | Feature gating is re-verified in the main process, not only in the UI.                                                   |
| BR-AIR-06 | Empty or whitespace-only input raises an error.                                                                          |
| BR-AIR-07 | A missing prompt or model-name environment variable raises an error.                                                     |
| BR-AIR-08 | The note-body hash at generation time is stored so later divergence from the source can be detected.                     |
| BR-AIR-09 | Deleting a task deletes its reflection.                                                                                  |

## 7. Screens and Interaction

Location: bottom of the task detail panel (`RightPanel`), below the note editor.

- Top: `Ask AI Reflection` button
- Below: reflection display area (read-only editor, Markdown rendered, minimum height 240px)
- Empty-state text: `No reflection generated yet...`
- Pressing the button when a reflection already exists shows a dialog
  - Title: `Do you want to delete the previous summary?`
  - Description: `To generate a new summary, the existing summary will be deleted.`
  - Buttons: `Cancel` / `Confirm`
- While generating, streamed text accumulates in the display area in real time.
- On completion, the `reflection_generated` analytics event is emitted.

## 8. Error Handling

| Situation                     | Handling                                                                                                                          |
| ----------------------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| Feature not on the plan       | `FEATURE_DISABLED` — "This feature requires a Pro plan."                                                                          |
| No input text                 | Error returned, generation aborted                                                                                                |
| Missing environment variables | Error returned, generation aborted                                                                                                |
| Model call failure            | `AI_ERROR` — "AI reflection is temporarily unavailable. Please try again later."                                                  |
| Error mid-stream              | Streaming state is cleared and an error toast is shown. This path is not a React Query mutation, so the toast is raised directly. |

## 9. Interface (IPC Channels)

| Channel                          | Direction       | Arguments         | Description                                        |
| -------------------------------- | --------------- | ----------------- | -------------------------------------------------- |
| `note.reflectionNoteStream`      | Renderer → Main | `taskId`, `text`  | Starts generation; resolves when the stream ends   |
| `note.reflectionNoteStreamChunk` | Main → Renderer | `{ chunk, done }` | Generated text chunk; `done: true` signals the end |
| `note.getReflection`             | Renderer → Main | `taskId`          | Reads the stored reflection                        |
| `note.deleteReflection`          | Renderer → Main | `taskId`          | Deletes the reflection                             |
| `note.removeReflectionListener`  | Renderer → Main | —                 | Removes the stream event listener                  |

## 10. Current Limitations and Future Work

- **The feature is effectively non-functional today because no API key is configured.** `geminiApiKey` in `src/config/env.ts` is hard-coded to an empty string and the environment-variable lookup is commented out.
- Since the default plan is `local`, `ai.reflection` is disabled for every user.
- `original_note_hash` is stored, but nothing surfaces a "this reflection is stale" hint when the note changes.
- The `note.deleteReflection` IPC channel is implemented but has no UI entry point.
- Users cannot edit the generated reflection directly or revise it without regenerating.
- The `ai.weekly-summary` and `ai.suggestion` feature flags are defined but unimplemented.
