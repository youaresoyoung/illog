# 설정 / 온보딩 기능 정의서

## 1. 개요

앱 설정을 변경하는 **설정 다이얼로그**와, 최초 실행 시 자동으로 표시되는 **온보딩 다이얼로그**를 제공하는 기능입니다. 두 화면은 동일한 컴포넌트를 모드만 바꿔 재사용합니다.

## 2. 목적 및 사용자 가치

- 첫 실행 시 익명 오류 리포팅 수집 여부를 사용자가 명시적으로 선택하게 한다(옵트인).
- 수집·미수집 정보를 투명하게 안내해 신뢰를 확보한다.
- 이후에도 언제든 설정을 되돌릴 수 있게 한다.

## 3. 진입 경로

| 진입        | 조건                                                |
| ----------- | --------------------------------------------------- |
| 설정 모드   | 좌측 내비게이션 패널 상단의 톱니 아이콘 클릭        |
| 온보딩 모드 | 앱 실행 시 온보딩 완료 여부가 `false`이면 자동 표시 |

## 4. 두 가지 모드

| 항목         | 설정 모드         | 온보딩 모드                                                                                             |
| ------------ | ----------------- | ------------------------------------------------------------------------------------------------------- |
| 제목         | `Settings`        | `Welcome to illog`                                                                                      |
| 접근성 라벨  | `Settings`        | `Welcome`                                                                                               |
| 안내 문구    | 없음              | `Before getting started, please review the anonymous error reporting settings to help improve the app.` |
| 하단 버튼    | `Close`           | `Get Started`                                                                                           |
| 닫기 시 동작 | 다이얼로그만 닫음 | 온보딩 완료 처리 후 닫음                                                                                |

## 5. 기능 상세

| ID        | 기능                  | 설명                                                                    |
| --------- | --------------------- | ----------------------------------------------------------------------- |
| FR-SET-01 | 설정 다이얼로그 열기  | 톱니 아이콘 클릭 시 설정 다이얼로그를 연다.                             |
| FR-SET-02 | 온보딩 자동 표시      | 앱 실행 시 온보딩 미완료 상태면 온보딩 모드 다이얼로그를 자동으로 연다. |
| FR-SET-03 | 오류 리포팅 설정 조회 | 현재 익명 오류 리포팅 활성화 여부를 조회해 토글 상태로 표시한다.        |
| FR-SET-04 | 오류 리포팅 토글      | 활성/비활성 상태를 전환하고 즉시 저장한다.                              |
| FR-SET-05 | 수집 정보 안내        | 수집하는 정보와 수집하지 않는 정보를 목록으로 안내한다.                 |
| FR-SET-06 | 온보딩 완료 처리      | 온보딩 모드에서 닫으면 완료 상태를 저장해 다시 표시되지 않게 한다.      |
| FR-SET-07 | 분석 이벤트 전송      | 다이얼로그 열림과 토글 변경 시 분석 이벤트를 전송한다.                  |

## 6. 설정 항목

현재 제공되는 설정은 **1개**다.

### 6.1 Anonymous Error Reporting (익명 오류 리포팅)

| 항목        | 값                                                                                                       |
| ----------- | -------------------------------------------------------------------------------------------------------- |
| 컨트롤      | 토글 스위치 (`role="switch"`)                                                                            |
| 기본값      | **비활성(OFF)** — 명시적 옵트인 방식                                                                     |
| 접근성 라벨 | `Anonymous Error Reporting Enable` / `Anonymous Error Reporting Disable`                                 |
| 설명        | `Error information that occurs during app usage is collected anonymously to help improve app stability.` |
| 저장 시점   | 토글 즉시                                                                                                |
| 로딩 중     | 반투명 처리 및 클릭 차단                                                                                 |

**수집하는 정보 (Collected Information)**

- 앱 버전, Electron 버전
- 운영체제 종류 및 버전
- 시스템 아키텍처 (x64, arm64 등)
- 오류 스택 트레이스
- 오류 발생 시각

**수집하지 않는 정보 (Information not collected)**

- 개인 식별 정보 (이메일, 이름 등)
- 로컬 데이터베이스 내용
- 로컬 파일 경로

**하단 고지 문구**

`This setting can be changed at any time, and collection will stop immediately when disabled. Error reports are used solely for app improvement purposes and are identified only by a randomly generated anonymous ID.`

## 7. 비즈니스 규칙

| ID        | 규칙                                                                                                            |
| --------- | --------------------------------------------------------------------------------------------------------------- |
| BR-SET-01 | 오류 리포팅 기본값은 비활성이며, 사용자가 명시적으로 켜야만 수집이 시작된다.                                    |
| BR-SET-02 | 토글 변경은 즉시 저장되고 즉시 적용된다(앱 재시작 불필요).                                                      |
| BR-SET-03 | 오류 리포팅 설정은 사용 분석(Umami) 활성화 여부와 **연동**된다. 리포팅을 끄면 사용 분석도 함께 꺼진다.          |
| BR-SET-04 | 온보딩은 1회만 표시된다. 완료 상태는 데이터베이스의 앱 설정 테이블에 저장된다.                                  |
| BR-SET-05 | 온보딩 모드에서 토글을 건드리지 않고 닫아도 온보딩은 완료 처리된다(기본값 비활성 유지).                         |
| BR-SET-06 | 설정 다이얼로그를 열 때마다 `settings_opened` 이벤트를, 토글할 때마다 `crash_report_toggled` 이벤트를 전송한다. |

## 8. 인터페이스 (IPC 채널)

| 채널                                | 인자          | 반환                       |
| ----------------------------------- | ------------- | -------------------------- |
| `crashReport.getSettings`           | —             | `{ enabled, anonymousId }` |
| `crashReport.updateSettings`        | `{ enabled }` | `{ enabled, anonymousId }` |
| `crashReport.isOnboardingCompleted` | —             | `boolean`                  |
| `crashReport.completeOnboarding`    | —             | —                          |

이 채널들은 오류 리포팅이 자기 자신의 오류를 다시 보고하는 순환을 막기 위해 **공통 오류 래퍼를 거치지 않고** 직접 등록된다.

## 9. 관련 기능

- 오류 리포팅 동작: [`crash-report`](../crash-report/spec.ko.md)
- 사용 분석 연동: [`usage-analytics`](../usage-analytics/spec.ko.md)
- 설정 저장 위치: [`data-storage`](../data-storage/spec.ko.md)

## 10. 현재 제한사항 및 향후 계획

- 설정 항목이 오류 리포팅 하나뿐이다. 테마·언어·주 시작 요일·데이터 경로 등은 설정할 수 없다.
- 온보딩이 단일 화면으로 끝나며, 앱 사용법 안내나 초기 프로젝트 설정 단계가 없다.
- 온보딩을 다시 보거나 초기화하는 수단이 없다.
- 토글 스위치가 공용 컴포넌트가 아닌 화면 내 인라인 구현이다(코드에 TODO 주석 존재).
- 데이터 백업·내보내기·초기화 같은 데이터 관리 설정이 없다.
