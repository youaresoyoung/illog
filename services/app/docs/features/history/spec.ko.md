# 히스토리(History) 화면 기능 정의서

## 1. 개요

날짜 제한 없이 **기록된 모든 로그**를 최신순으로 나열하는 화면입니다. Today 화면이 오늘 구간만 보여주는 것과 달리, 전체 기록을 한 목록에서 훑어볼 수 있습니다.

## 2. 목적 및 사용자 가치

- 이전에 어떤 일을 기록했는지 시간 제약 없이 다시 찾아본다.
- 과거 로그의 노트·회고에 접근하는 진입점을 제공한다.

## 3. 진입 경로

| 항목            | 값                         |
| --------------- | -------------------------- |
| 라우트          | `/history`                 |
| 좌측 내비게이션 | `History` (아이콘 `clock`) |
| 화면 제목       | `History`                  |

## 4. 조회 범위

| 항목         | 값                 |
| ------------ | ------------------ |
| 필터         | 없음 (전체 조회)   |
| 제외 대상    | 소프트 삭제된 로그 |
| 정렬         | 생성일 내림차순    |
| 페이지네이션 | 없음 (전량 로딩)   |

## 5. 기능 상세

| ID         | 기능             | 설명                                                               |
| ---------- | ---------------- | ------------------------------------------------------------------ |
| FR-HIST-01 | 전체 로그 조회   | 삭제되지 않은 모든 로그를 태그·프로젝트·유형 정보와 함께 조회한다. |
| FR-HIST-02 | 로그 카드 표시   | Today 화면과 동일한 로그 카드 컴포넌트를 사용한다.                 |
| FR-HIST-03 | 로그 상세 열기   | 카드를 클릭하면 우측 상세 패널이 열린다.                           |
| FR-HIST-04 | 인라인 편집      | 카드에서 제목·설명·상태·시간·프로젝트·유형·태그를 직접 수정한다.   |
| FR-HIST-05 | 로그 삭제        | 카드 우클릭 컨텍스트 메뉴 → `Delete` → 확인 다이얼로그.            |
| FR-HIST-06 | 빈 상태 안내     | 로그가 없으면 안내 문구를 표시한다.                                |
| FR-HIST-07 | 로딩 / 오류 상태 | 로딩 중 안내 문구, 오류 시 재시도 버튼을 제공한다.                 |

## 6. 상태별 표시

| 상태      | 표시 내용                                                |
| --------- | -------------------------------------------------------- |
| 로딩 중   | `Loading tasks...` (`role="status"`, `aria-busy="true"`) |
| 오류      | 사용자 메시지 + `Retry` 버튼                             |
| 로그 없음 | `No tasks found in history`                              |

## 7. 비즈니스 규칙

| ID         | 규칙                                                               |
| ---------- | ------------------------------------------------------------------ |
| BR-HIST-01 | 소프트 삭제된 로그는 표시되지 않는다.                              |
| BR-HIST-02 | 정렬은 생성일 내림차순으로 고정이며 변경할 수 없다.                |
| BR-HIST-03 | 전체 로그를 한 번에 로딩하며, 무한 스크롤이나 페이지네이션이 없다. |
| BR-HIST-04 | 카드에서의 편집·삭제 동작은 Today 화면과 동일하다.                 |
| BR-HIST-05 | 히스토리 조회 결과는 프로젝트 목록의 완료율 계산에도 재사용된다.   |

## 8. 관련 기능

- 로그 CRUD 및 카드 동작: [`task`](../task/spec.ko.md)
- 상세 패널 구성: [`app-shell`](../app-shell/spec.ko.md)

## 9. 현재 제한사항 및 향후 계획

- **이 화면은 임시 화면이다.** 코드 주석에 따르면 향후 회고(Reflection) 화면과 하나로 통합될 예정이며, 그때까지만 노출된다.
- 회고(Reflection) 화면은 라우트와 컴포넌트 골격만 존재하고 내비게이션·라우터 모두에서 주석 처리되어 접근할 수 없다.
- 검색·기간 필터·상태 필터 UI가 없다.
- 페이지네이션이 없어 로그가 많아지면 초기 로딩 부담이 커진다.
- 날짜별 그룹 헤더가 없어 목록이 길어지면 시점 파악이 어렵다.
- 페이지뷰 분석 이벤트 전송이 TODO 주석 상태로 비활성화되어 있다.
