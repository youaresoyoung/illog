# 프로젝트 인사이트(Project Insights) 기능 정의서

## 1. 개요

선택한 프로젝트 하나에 대해 **진행 현황과 작업 유형별 지표**를 보여주는 분석 화면입니다. 좌측 사이드바에서 프로젝트를 고르면 우측에 개요 지표, 작업 유형 분석, 세부 유형 테이블, 소속 로그 목록이 표시됩니다.

## 2. 목적 및 사용자 가치

- 프로젝트 단위로 진행률과 투입 시간을 정량적으로 파악한다.
- 프로젝트 안에서 어떤 성격의 작업에 시간이 몰렸는지 확인한다.

## 3. 진입 경로

| 항목            | 값                                                     |
| --------------- | ------------------------------------------------------ |
| 라우트          | `/projects`                                            |
| 좌측 내비게이션 | `Projects` (아이콘 `folder`)                           |
| 화면 제목       | `Projects` (프로젝트 선택 시 `Projects: <프로젝트명>`) |

## 4. 화면 구성

```
┌──────────┬───────────────┬────────────────────────────────────┐

│          │ ┌───────────┐ │ Project Overview                   │
```

## 5. 기능 상세

| ID       | 기능               | 설명                                                                                |
| -------- | ------------------ | ----------------------------------------------------------------------------------- |
| FR-PI-01 | 프로젝트 목록 표시 | 삭제되지 않은 모든 프로젝트를 완료율 막대와 함께 좌측 사이드바에 표시한다.          |
| FR-PI-02 | 프로젝트 선택      | 목록에서 프로젝트를 선택하면 우측 분석 영역이 해당 프로젝트로 전환된다.             |
| FR-PI-03 | 최초 자동 선택     | 선택된 프로젝트가 없고 프로젝트가 1개 이상 있으면 첫 번째 프로젝트를 자동 선택한다. |
| FR-PI-04 | 개요 지표          | 선택 프로젝트의 총계 지표 6종을 표시한다.                                           |
| FR-PI-05 | 작업 유형 분석     | 작업 유형별 지표를 정렬 가능한 테이블과 도넛 차트로 표시한다.                       |
| FR-PI-06 | 세부 유형 테이블   | 세부 유형별 지표를 정렬 가능한 테이블로 표시한다.                                   |
| FR-PI-07 | 소속 로그 목록     | 선택 프로젝트에 속한 로그를 카드 목록으로 표시한다.                                 |
| FR-PI-08 | 로그 상세 열기     | 로그 카드 클릭 시 우측 상세 패널이 열린다.                                          |

### 5.1 개요 지표 (FR-PI-04)

| 지표               | 산출 방식                                              |
| ------------------ | ------------------------------------------------------ |
| `Total Tasks`      | 프로젝트 소속 로그 수                                  |
| `Completed`        | 상태가 `done`인 로그 수                                |
| `In Progress`      | 상태가 `in_progress`인 로그 수                         |
| `Todo`             | 상태가 `todo`인 로그 수                                |
| `Completion Rate`  | 완료 수 ÷ 전체 수 × 100 (소수 1자리). 로그가 없으면 0% |
| `Total Time Spent` | 모든 로그의 (종료 − 시작) 합계, 소수 1자리 시간        |

### 5.2 작업 유형 분석 테이블 (FR-PI-05)

| 열                | 내용                             | 정렬      |
| ----------------- | -------------------------------- | --------- |
| `Type`            | 작업 유형 배지(이름 + 색상)      | 이름 기준 |
| `Count`           | 해당 유형 로그 수                | 숫자 기준 |
| `Completion Rate` | 유형 내 완료율(소수 1자리)       | 숫자 기준 |
| `Total Time`      | 유형별 총 소요 시간. 0이면 `N/A` | 숫자 기준 |

- 도넛 차트가 함께 표시되어 유형별 시간 비중을 시각화한다.

### 5.3 세부 유형 테이블 (FR-PI-06)

| 열                | 내용                     |
| ----------------- | ------------------------ |
| `Subtype`         | 세부 유형 배지           |
| `Parent Type`     | 상위 작업 유형 배지      |
| `Count`           | 해당 세부 유형 로그 수   |
| `Completion Rate` | 세부 유형 내 완료율      |
| `Total Time`      | 세부 유형별 총 소요 시간 |

- 세부 유형 지표가 하나도 없으면 이 섹션 전체를 표시하지 않는다.

### 5.4 프로젝트 목록 항목 (FR-PI-01)

| 요소      | 내용                                           |
| --------- | ---------------------------------------------- |
| 이름      | 프로젝트명 (길면 말줄임)                       |
| 완료율    | `(NN %)` 형식, 소수점 없음                     |
| 진행 막대 | 완료율 기준 가로 막대. 채움 색은 프로젝트 색상 |
| 선택 표시 | 선택된 항목은 테두리 색으로 구분               |

## 6. 상태별 표시

| 상태               | 표시 내용                            |
| ------------------ | ------------------------------------ |
| 프로젝트 미선택    | `Select a project to view insights`  |
| 로딩 중            | `Loading...`                         |
| 오류               | `Error loading tasks: <오류 메시지>` |
| 로그 없음          | `No tasks yet`                       |
| 테이블 데이터 없음 | 각 테이블의 빈 상태 문구             |

## 7. 비즈니스 규칙

| ID       | 규칙                                                                                                |
| -------- | --------------------------------------------------------------------------------------------------- |
| BR-PI-01 | 프로젝트 목록의 완료율은 전체 로그를 프로젝트별로 묶어 계산한다.                                    |
| BR-PI-02 | 소요 시간은 시작·종료 시각이 모두 있을 때만 계산되며, 한쪽이라도 없으면 0분이다.                    |
| BR-PI-03 | 완료율은 상태 `done` 기준으로 계산한다(주간 요약의 완료 수는 `doneAt` 기준이라 판정 기준이 다르다). |
| BR-PI-04 | 선택된 프로젝트 ID는 전역 UI 상태로 유지되어 화면을 벗어났다 돌아와도 보존된다.                     |
| BR-PI-05 | 프로젝트가 지정되지 않은 로그는 이 화면에서 조회되지 않는다.                                        |
| BR-PI-06 | 테이블 기본 정렬은 내림차순이다.                                                                    |

## 9. 현재 제한사항 및 향후 계획

- 기간 필터가 없어 항상 프로젝트의 **전체 기간** 데이터를 집계한다.
- 프로젝트 간 비교 화면이 없다.
- 리드 타임(생성 → 완료 소요 시간) 계산 함수가 구현되어 있으나 화면 어디에도 표시되지 않는다. `TaskTypeMetrics`의 `avgCompletionMinutes` 필드도 마찬가지로 미사용이다.
- `ProjectSelector` 컴포넌트가 구현되어 있으나 이 화면에서 사용되지 않는다(좌측 사이드바 목록으로 대체됨).
- 미분류(프로젝트 없음) 로그를 확인할 경로가 없다.
- 지표를 내보내기(CSV 등)할 수 없다.
