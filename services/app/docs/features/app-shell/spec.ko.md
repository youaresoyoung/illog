# 앱 셸(App Shell) 기능 정의서

## 1. 개요

애플리케이션의 **외곽 구조**를 담당하는 기능입니다. 데스크톱 윈도우, 시스템 트레이, 애플리케이션 메뉴, 화면 레이아웃과 라우팅, 다크/라이트 테마를 포함합니다.

## 2. 목적 및 사용자 가치

- 데스크톱 앱다운 동작(창 크기 기억, 트레이 상주, 시스템 메뉴)을 제공한다.
- 화면 간 이동과 상세 패널 열기를 일관된 구조로 제공한다.
- OS 테마 설정을 따라 자동으로 외관을 맞춘다.

## 3. 기능 상세

| ID          | 기능              | 설명                                                      |
| ----------- | ----------------- | --------------------------------------------------------- |
| FR-SHELL-01 | 메인 윈도우 생성  | 앱 준비 완료 시 메인 윈도우를 생성한다.                   |
| FR-SHELL-02 | 윈도우 상태 기억  | 창의 위치와 크기를 저장해 다음 실행 시 복원한다.          |
| FR-SHELL-03 | 시스템 트레이     | 트레이 아이콘과 컨텍스트 메뉴를 등록한다.                 |
| FR-SHELL-04 | 애플리케이션 메뉴 | 플랫폼별 기본 메뉴를 구성한다.                            |
| FR-SHELL-05 | 화면 라우팅       | 해시 기반 라우터로 4개 화면을 전환한다.                   |
| FR-SHELL-06 | 좌측 내비게이션   | 로고, 화면 목록, 설정 버튼을 고정 패널로 표시한다.        |
| FR-SHELL-07 | 상세 패널         | 로그 상세를 우측 오버레이 패널로 표시한다.                |
| FR-SHELL-08 | 테마 동기화       | OS 다크모드 설정 변경을 감지해 앱 테마를 전환한다.        |
| FR-SHELL-09 | macOS 동작        | Dock 아이콘 설정 및 창 재생성 등 macOS 관례를 따른다.     |
| FR-SHELL-10 | 개발 모드 지원    | 개발 서버 연결, DevTools, React DevTools 확장을 지원한다. |

## 4. 윈도우 사양

| 항목           | 값                                           |
| -------------- | -------------------------------------------- |
| 기본 크기      | 1240 × 760                                   |
| 최소 크기      | 1240 × 760                                   |
| 초기 표시      | 숨김 상태로 생성 후 렌더링 준비 완료 시 표시 |
| 창 제목        | 앱 이름                                      |
| 위치/크기 저장 | `electron-window-state`로 자동 저장·복원     |

### 4.1 개발 / 프로덕션 로딩 방식

| 모드     | 동작                                                                                                                                                                                        |
| -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 개발     | Vite 개발 서버 URL을 로드한다. 로드 실패 시 **최대 3회** 재시도하며 대기 시간이 `500ms × 시도 횟수`로 늘어난다. DevTools를 별도 창(detach)으로 연다. React Developer Tools 확장을 설치한다. |
| 프로덕션 | 빌드된 렌더러 HTML 파일을 로드한다.                                                                                                                                                         |

### 4.2 macOS 전용 동작

| 동작             | 설명                                                   |
| ---------------- | ------------------------------------------------------ |
| Dock 아이콘      | 앱 아이콘 파일을 Dock 아이콘으로 설정한다.             |
| 모든 창 닫힘     | 앱을 종료하지 않는다(다른 플랫폼은 종료).              |
| Dock 아이콘 클릭 | 열린 창이 없으면 메인 윈도우와 트레이를 다시 생성한다. |

## 5. 시스템 트레이

| 항목            | 값                                                                           |
| --------------- | ---------------------------------------------------------------------------- |
| 아이콘          | 트레이 전용 아이콘. macOS에서는 템플릿 이미지로 설정해 다크/라이트 자동 대응 |
| 툴팁            | 앱 이름                                                                      |
| 하이라이트 모드 | macOS에서 `always`                                                           |
| 컨텍스트 메뉴   | `Open illog` / 구분선 / `Quit`                                               |
| 아이콘 클릭     | 창이 보이는 상태면 포커스, 숨겨진 상태면 표시                                |
| `Open illog`    | 최소화 상태면 복원 후 표시·포커스                                            |

트레이 인스턴스는 싱글턴으로 관리되어 중복 생성되지 않는다.

| 메뉴        | 항목                                                                   | 비고       |

## 7. 화면 구조 및 라우팅

### 7.1 라우트

라우터는 **해시 기반**(`createHashRouter`)이다.

| 경로          | 화면       | 내비게이션 라벨 | 아이콘           |
| ------------- | ---------- | --------------- | ---------------- |
| `/`           | Today      | `Today`         | `calendar_today` |
| `/this-week`  | This Week  | `This Week`     | `calendar_week`  |
| `/history`    | History    | `History`       | `clock`          |
| `/projects`   | Projects   | `Projects`      | `folder`         |
| `/reflection` | Reflection | —               | —                |

`/reflection` 라우트와 내비게이션 항목은 모두 주석 처리되어 접근할 수 없다.

### 7.2 레이아웃

```
┌────────────┬──────────────────────────────┬─────────────────┐
│ LeftPanel  │        MainContent           │   RightPanel    │
│ (고정 256px)│      (중앙 정렬 960px)        │  (오버레이 720px)│
│            │                              │                 │
│ [로고] [⚙] │  <Outlet />                  │  로그 상세       │
│            │                              │  - 상태          │
│ Today      │                              │  - 프로젝트/유형  │
│ This Week  │                              │  - 제목/설명     │
│ History    │                              │  - 태그 / 시간   │
│ Projects   │                              │  - 노트 에디터   │
│            │                              │  - AI 회고       │
└────────────┴──────────────────────────────┴─────────────────┘
```

- 좌측 패널: 로고(테마에 따라 라이트/다크 이미지 교체), 화면 목록, 설정 버튼
- 메인 영역: 좌측 256px 오프셋, 폭 960px 중앙 정렬, 상단 여백 있음
- 우측 패널: `slideRight` 애니메이션 오버레이. 로그가 선택된 경우에만 렌더링

### 7.3 전역 UI 상태

| 상태                       | 용도                                       |
| -------------------------- | ------------------------------------------ |
| `currentTaskId`            | 상세 패널에 표시할 로그 ID                 |
| `isTaskNoteOpen`           | 상세 패널 열림 여부                        |
| `currentSelectedProjectId` | 프로젝트 인사이트 화면에서 선택된 프로젝트 |
| `isDarkMode`               | 다크모드 여부                              |

## 8. 테마

| 항목         | 동작                                                                               |
| ------------ | ---------------------------------------------------------------------------------- |
| 초기값       | `prefers-color-scheme` 미디어 쿼리로 판단                                          |
| OS 변경 감지 | 메인 프로세스가 `nativeTheme` 변경을 감지해 렌더러에 `theme.changed` 이벤트를 전송 |
| 적용 방식    | 문서 루트에 `theme-dark` 클래스를 토글                                             |
| 로고         | 테마에 따라 라이트/다크 로고 이미지를 교체                                         |

- 사용자가 앱 안에서 테마를 수동 전환하는 UI는 없다(OS 설정을 따른다).

## 9. 앱 생명주기

```
앱 시작
  → (Windows) Squirrel 설치 이벤트 처리
  → Sentry 초기화
  → app.whenReady()
      → (개발) React DevTools 설치
      → nativeTheme 변경 리스너 등록
      → DB 열기 + 마이그레이션 + 시드
      → 저장소/서비스/IPC 핸들러 등록
      → app_launched 분석 이벤트 전송
      → CSP 설정
      → 애플리케이션 메뉴 구성
      → (macOS) Dock 아이콘 설정
      → 메인 윈도우 생성
      → 자동 업데이터 초기화 및 업데이트 확인
      → 트레이 생성
앱 종료 (before-quit)
  → 분석 서비스 종료(flush)
  → 크래시 리포트 서비스 종료(flush)
```

## 11. 현재 제한사항 및 향후 계획

- 딥링크 수신 인터페이스(`events.onDeepLink`)가 preload에 노출되어 있으나, 메인 프로세스에서 `deep-link` 이벤트를 전송하는 코드가 없어 동작하지 않는다.
- 앱 내에서 테마를 수동으로 전환할 수 없다.
- 좌측 내비게이션을 접거나 폭을 조절할 수 없다.
- 창을 닫아도 트레이에 상주시키는 옵션(백그라운드 실행)이 없다.
- 전역 단축키가 없다.
- 다중 윈도우를 지원하지 않는다.
- 메인 콘텐츠 폭이 960px로 고정되어 넓은 화면을 활용하지 못한다.
- `theme_changed` 분석 이벤트 상수는 정의되어 있으나 전송되지 않는다.
