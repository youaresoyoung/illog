# 주간 요약(Weekly Summary) 기능 정의서

## 1. 개요

한 주 동안 기록된 로그를 집계해 **통계·분포·요일별 내역**을 보여주는 분석 화면입니다. 프로젝트 / 작업 유형 / 세부 유형을 축으로 단계적으로 파고드는(드릴다운) 분석을 제공합니다.

## 2. 목적 및 사용자 가치

- 한 주에 무엇에 얼마나 시간을 썼는지 정량적으로 파악한다.
- "프로젝트 A 안에서는 어떤 유형의 작업이 많았나"처럼 계층적으로 원인을 좁혀 들어갈 수 있게 한다.

## 3. 진입 경로

| 항목            | 값                                   |
| --------------- | ------------------------------------ |
| 라우트          | `/this-week`                         |
| 좌측 내비게이션 | `This Week` (아이콘 `calendar_week`) |
| 화면 제목       | `Weekly Summary`                     |

## 4. 주(Week) 기준 및 이동

| 항목         | 값                                                                       |
| ------------ | ------------------------------------------------------------------------ |
| 주 시작 요일 | **월요일** 고정                                                          |
| 기준 시간대  | 사용자 시스템 시간대(`Intl.DateTimeFormat().resolvedOptions().timeZone`) |
| 조회 구간    | 해당 주의 시작 ~ 종료 (구간 겹침 기준)                                   |
| 날짜 라벨    | `MMMM d - d, yyyy` 형식 (예: `July 20 - 26, 2026`)                       |

- `Prev` / `Next` 버튼으로 주 단위 이동한다.
- 현재 주에서는 `Next` 버튼이 비활성화되어 **미래 주로 이동할 수 없다**.
- 주를 이동하면 드릴다운 필터가 초기화된다.

## 5. 기능 상세

| ID         | 기능            | 설명                                                                 |
| ---------- | --------------- | -------------------------------------------------------------------- |
| FR-WEEK-01 | 주간 통계 요약  | 완료 수, 총 기록 시간, 프로젝트 수, 일평균 완료 수를 표시한다.       |
| FR-WEEK-02 | 분석 기준 선택  | `By Project` / `By Task Type` / `By Sub Type` 중 최상위 축을 고른다. |
| FR-WEEK-03 | 생산성 카드     | 현재 단계의 세그먼트를 카드 목록으로 표시한다.                       |
| FR-WEEK-04 | 시간 분포 차트  | 현재 단계의 세그먼트를 도넛 차트로 표시한다.                         |
| FR-WEEK-05 | 드릴다운        | 세그먼트를 클릭해 하위 단계로 파고든다.                              |
| FR-WEEK-06 | 브레드크럼 탐색 | 현재 위치를 경로로 표시하고 상위 단계로 되돌아간다.                  |
| FR-WEEK-07 | 요일별 내역     | 월~일 요일별 로그 목록과 합계 시간을 표시한다.                       |
| FR-WEEK-08 | 주간 캘린더 뷰  | 7일 타임그리드로 전환한다.                                           |
| FR-WEEK-09 | 주 이동         | 이전/다음 주로 이동한다.                                             |

### 5.1 주간 통계 항목 (FR-WEEK-01)

| 항목                | 산출 방식                                                                     |
| ------------------- | ----------------------------------------------------------------------------- |
| `Tasks Completed`   | 완료 시각(`doneAt`)이 있는 로그 수                                            |
| `Total Time Logged` | 모든 로그의 (종료 − 시작) 합계, 소수 1자리 시간으로 표기                      |
| `Projects`          | 로그에 등장한 고유 프로젝트 수                                                |
| `Avg Tasks/Day`     | 완료 수 ÷ 기준 일수. 과거 주는 7일, 현재 주는 **경과한 일수**(최소 1, 최대 7) |

### 5.2 드릴다운 계층 (FR-WEEK-05)

| 최상위 축      | 1단계       | 2단계                        | 3단계(리프)                  |
| -------------- | ----------- | ---------------------------- | ---------------------------- |
| `By Project`   | 프로젝트별  | 선택 프로젝트 내 작업 유형별 | 선택 유형 내 세부 유형별     |
| `By Task Type` | 작업 유형별 | 선택 유형 내 프로젝트별      | 선택 프로젝트 내 세부 유형별 |
| `By Sub Type`  | 세부 유형별 | 선택 세부 유형 내 프로젝트별 | — (2단계가 리프)             |

- 리프 단계에서는 세그먼트 클릭이 비활성화된다.
- 브레드크럼의 루트 라벨은 축에 따라 `All Projects` / `All Task Types` / `All Sub Types`로 표시된다.

### 5.3 세그먼트 집계 규칙

| 항목    | 규칙                                                                         |
| ------- | ---------------------------------------------------------------------------- |
| 집계 값 | 세그먼트별 로그 수와 소요 시간 합계                                          |
| 비율    | 세그먼트 소요 시간 ÷ 전체 소요 시간 × 100. 전체가 0이면 0%                   |
| 정렬    | 소요 시간 내림차순                                                           |
| 미분류  | 프로젝트/유형/세부 유형이 없는 로그는 `etc` 세그먼트로 묶인다. 색상은 `gray` |
| 색상    | 해당 프로젝트/유형/세부 유형에 지정된 색상                                   |

### 5.4 요일별 내역 (FR-WEEK-07)

- 월요일부터 7일간 순서대로 표시한다.
- 로그의 **시작 시각 날짜**를 기준으로 그룹핑한다.
- 로그가 하나도 없는 요일은 표시하지 않는다.
- 요일 라벨 형식: `EEEE, MMM d` (예: `Monday, Jul 20`)
- 요일별 합계 소요 시간을 함께 표시한다.

## 6. 화면 구성

```
┌────────────────────────────────────────────────────────────┐
│ Weekly Summary       [카드│캘린더]    [< Prev] [Next >]    │
│ July 20 - 26, 2026                                         │
├────────────────────────────────────────────────────────────┤
│ [완료 수] [총 시간] [프로젝트 수] [일평균]                  │  ← StatsSummary
├────────────────────────────────────────────────────────────┤
│ By Project | By Task Type | By Sub Type                    │  ← ViewModeSelector
├────────────────────────────────────────────────────────────┤
│ All Projects > Project: illog > Task Type: Development     │  ← 브레드크럼
├──────────────────────────────────┬─────────────────────────┤
│ [생산성 카드 목록]                │ [시간 분포 도넛]        │
├──────────────────────────────────┴─────────────────────────┤
│ Daily Breakdown                                            │
│  Monday, Jul 20   ─ 3h 20m                                 │
│  Tuesday, Jul 21  ─ 5h 10m                                 │
└────────────────────────────────────────────────────────────┘
```

캘린더 뷰로 전환하면 통계·분석·요일별 내역 대신 7일 타임그리드가 표시된다.

## 7. 상태별 표시

| 상태                    | 표시 내용                                     |
| ----------------------- | --------------------------------------------- |
| 로딩 중                 | 화면 제목 + `Loading...` (`aria-busy="true"`) |
| 오류                    | 화면 제목 + 사용자 메시지 + `Retry` 버튼      |
| 세그먼트 없음           | 현재 단계 제목 + `No data available`          |
| 시간 데이터 없음 (도넛) | `No time data available`                      |
| 로그 없음 (요일별)      | `No tasks logged for this week`               |

## 8. 비즈니스 규칙

| ID         | 규칙                                                                                                 |
| ---------- | ---------------------------------------------------------------------------------------------------- |
| BR-WEEK-01 | 주 시작 요일은 월요일로 고정된다(사용자 설정 불가).                                                  |
| BR-WEEK-02 | 미래 주로 이동할 수 없다.                                                                            |
| BR-WEEK-03 | 주가 바뀌면 드릴다운 선택이 초기화된다.                                                              |
| BR-WEEK-04 | 소요 시간은 종료 시각과 시작 시각이 **모두 있을 때만** 계산된다. 한쪽이라도 없으면 0분으로 집계된다. |
| BR-WEEK-05 | 완료 수는 상태가 아니라 완료 시각(`doneAt`)의 존재 여부로 판정한다.                                  |
| BR-WEEK-06 | 현재 주의 일평균은 7일이 아니라 경과 일수로 나눈다.                                                  |
| BR-WEEK-07 | 리프 단계에서는 더 이상 드릴다운할 수 없다.                                                          |
| BR-WEEK-08 | 뷰 모드(카드/캘린더) 선택은 화면 로컬 상태이며 저장되지 않는다.                                      |

- 조회 대상 데이터: [`task`](../task/spec.ko.md)
- 주간 캘린더 렌더링: [`calendar-view`](../calendar-view/spec.ko.md)
- 주간 회고 입력: [`weekly-reflection`](../weekly-reflection/spec.ko.md)

## 10. 현재 제한사항 및 향후 계획

- **주간 회고(`WeeklyReflection`) 컴포넌트가 이 화면에서 주석 처리되어 노출되지 않는다.** 구현은 완료되어 있다.
- 페이지뷰 분석 이벤트 전송이 TODO 주석 상태로 비활성화되어 있다.
- 태그를 분석 축으로 사용할 수 없다.
- 주 시작 요일을 사용자가 선택할 수 없다(코드에 향후 지원 예정 주석 존재).
- 통계를 CSV·이미지 등으로 내보낼 수 없다.
- 이전 주와의 비교(증감 표시)가 없다.
- 월간·연간 단위 요약이 없다.
