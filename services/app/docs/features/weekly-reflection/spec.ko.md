# 주간 회고(Weekly Reflection) 기능 정의서

> ⚠️ **현재 상태: 구현 완료 / 화면 미노출.** 데이터 모델·저장소·IPC·UI 컴포넌트가 모두 구현되어 있으나, 주간 요약 화면(`ThisWeek.tsx`)에서 렌더링 코드가 주석 처리되어 사용자에게 노출되지 않습니다.

## 1. 개요

한 주 단위로 **주요 성과, 개선할 점, 다음 주 집중 영역**을 직접 작성해 남기는 기능입니다. 로그 단위의 AI 회고와 달리, 사용자가 직접 작성하는 주 단위 회고입니다.

## 2. 목적 및 사용자 가치

- 자동 집계된 통계만으로는 남지 않는 주관적 판단과 다음 주 계획을 기록한다.
- 주 단위로 회고 루틴을 만든다.

## 3. 용어 정의

| 용어                          | 정의                                                            |
| ----------------------------- | --------------------------------------------------------------- |
| 주 식별자(weekId)             | ISO 주 표기 문자열. `YYYY-Www` 형식 (예: `2026-W30`)            |
| 주요 성과(Accomplishment)     | 완료 여부를 토글할 수 있는 항목. `{ id, text, completed }` 구조 |
| 개선할 점(Improvement)        | 단순 텍스트 항목                                                |
| 다음 주 집중(Next Week Focus) | 선택된 태그 ID 목록                                             |

## 4. 데이터 모델

테이블 `weekly_reflection` (`src/main/database/schema/weeklyReflection.ts`)

| 컬럼              | 타입               | 제약 / 기본값                                           |
| ----------------- | ------------------ | ------------------------------------------------------- |
| `id`              | text               | PK, UUID 자동 생성                                      |
| `week_id`         | text               | NOT NULL, UNIQUE                                        |
| `accomplishments` | text               | NOT NULL, 기본값 `[]`. `{ id, text, completed }[]` JSON |
| `improvements`    | text               | NOT NULL, 기본값 `[]`. `string[]` JSON                  |
| `next_week_focus` | text               | NOT NULL, 기본값 `[]`. 태그 ID `string[]` JSON          |
| `created_at`      | integer(timestamp) | NOT NULL, 기본값 현재 시각                              |
| `updated_at`      | integer(timestamp) | NOT NULL, 기본값 현재 시각                              |

인덱스: `week_id`

- 세 목록 필드는 모두 **JSON 문자열로 직렬화**되어 단일 컬럼에 저장된다. 조회 시 파싱해 배열로 복원한다.
- 주 식별자는 주 시작 요일을 월요일로 계산한 ISO 주 번호를 사용한다.

## 5. 기능 상세

| ID       | 기능           | 설명                                                                  |
| -------- | -------------- | --------------------------------------------------------------------- |
| FR-WR-01 | 주간 회고 조회 | 주 식별자로 회고를 조회한다. 없으면 빈 값을 반환한다.                 |
| FR-WR-02 | 주간 회고 저장 | 주 식별자로 회고를 저장한다. 없으면 생성하고 있으면 수정한다(upsert). |
| FR-WR-03 | 성과 추가      | 입력한 텍스트로 성과 항목을 추가한다.                                 |
| FR-WR-04 | 성과 완료 토글 | 성과 항목의 완료 상태를 전환한다.                                     |
| FR-WR-05 | 성과 삭제      | 성과 항목을 제거한다.                                                 |
| FR-WR-06 | 개선점 추가    | 입력한 텍스트로 개선점 항목을 추가한다.                               |
| FR-WR-07 | 개선점 삭제    | 개선점 항목을 제거한다.                                               |
| FR-WR-08 | 집중 태그 토글 | 태그를 다음 주 집중 목록에 넣거나 뺀다.                               |
| FR-WR-09 | 자동 저장      | 변경 후 1초 뒤 자동 저장한다.                                         |

## 6. 비즈니스 규칙

| ID       | 규칙                                                                                                        |
| -------- | ----------------------------------------------------------------------------------------------------------- |
| BR-WR-01 | 주 하나에 회고는 최대 1개다(주 식별자 UNIQUE).                                                              |
| BR-WR-02 | 저장은 upsert 방식이므로 사용자가 "생성"과 "수정"을 구분할 필요가 없다.                                     |
| BR-WR-03 | 부분 저장이 가능하다. 전달된 필드만 갱신되고 나머지는 보존된다.                                             |
| BR-WR-04 | 자동 저장 디바운스는 **1초**다.                                                                             |
| BR-WR-05 | 성과·개선점 입력에서 공백만 입력하면 추가되지 않는다.                                                       |
| BR-WR-06 | 성과 항목의 ID는 클라이언트에서 UUID로 생성한다.                                                            |
| BR-WR-07 | 다음 주 집중은 태그 ID만 저장한다. 태그가 삭제되면 해당 ID는 남지만 화면에서는 선택 목록에 나타나지 않는다. |
| BR-WR-08 | 입력 창에서 Enter 키를 누르면 항목이 추가된다.                                                              |

## 7. 화면 및 인터랙션

주간 요약 화면(`/this-week`) 최하단에 배치되도록 설계되어 있다.

```
Weekly Reflection

  Key Accomplishments
    ☑ 릴리스 v0.1.5 배포            [×]
    ☐ 온보딩 플로우 개선            [×]
    [Add accomplishment...        ] [Add]

  Areas for Improvement
    ! 테스트 커버리지 부족           [×]
    [Add improvement area...      ] [Add]

  Next Week Focus
    [태그A] [태그B] [태그C]   ← 선택된 태그는 강조 표시
```

- 완료 처리된 성과는 취소선과 흐린 글자색으로 표시된다.
- 태그가 하나도 없으면 `No tags available. Create tags in your tasks first.` 문구를 표시한다.

## 8. 예외 및 오류 처리

| 상황                    | 처리                                           |
| ----------------------- | ---------------------------------------------- |
| 회고 생성 실패          | `Failed to create weekly reflection`           |
| 존재하지 않는 회고 수정 | `Weekly reflection not found`                  |
| 저장 실패               | 전역 뮤테이션 오류 처리기가 오류 토스트를 표시 |

## 9. 인터페이스 (IPC 채널)

| 채널                      | 인자                                                            | 반환            |
| ------------------------- | --------------------------------------------------------------- | --------------- |
| `weeklyReflection.get`    | `weekId`                                                        | 회고 또는 빈 값 |
| `weeklyReflection.upsert` | `weekId`, `{ accomplishments?, improvements?, nextWeekFocus? }` | 회고            |

## 10. 현재 제한사항 및 향후 계획

- **주간 요약 화면에서 렌더링이 주석 처리되어 있어 실제로 사용할 수 없다.** 활성화하려면 `ThisWeek.tsx`의 `weekId` 계산과 `<WeeklyReflection />` 렌더링 주석을 해제해야 한다.
- 주를 이동해도 회고가 함께 따라가도록 연결되어 있지 않다(주석 처리된 코드는 항상 현재 주를 사용).
- 항목 순서를 변경할 수 없다.
- 성과·개선점을 수정할 수 없다(삭제 후 재입력만 가능).
- 이전 주 회고를 조회하는 별도 화면이 없다.
- `weekly_reflection_saved` 분석 이벤트 상수는 정의되어 있으나 전송되지 않는다.
- `ai.weekly-summary` 기능 플래그가 정의되어 있어, 향후 AI가 주간 회고 초안을 제안하는 방향이 계획되어 있다.
