# 오늘 로그(Today) 화면 기능 정의서

## 1. 개요

앱의 기본 진입 화면으로, **오늘 구간에 해당하는 로그**를 보여주고 새 로그를 만드는 화면입니다. 카드 뷰와 캘린더 뷰를 전환할 수 있습니다.

## 2. 목적 및 사용자 가치

- 앱을 열자마자 오늘 한 일을 확인하고 바로 기록을 추가할 수 있게 한다.
- 시간이 입력된 로그는 캘린더로 전환해 하루의 시간 배분을 시각적으로 확인할 수 있게 한다.

## 3. 진입 경로

| 항목            | 값                                |
| --------------- | --------------------------------- |
| 라우트          | `/` (인덱스 라우트)               |
| 좌측 내비게이션 | `Today` (아이콘 `calendar_today`) |
| 화면 제목       | `Today's Log`                     |

## 4. 조회 범위

오늘 로그 목록은 다음 구간 필터로 조회한다.

| 항목 | 값                              |
| ---- | ------------------------------- |
| 시작 | 오늘 `00:00:00.000` (로컬 시각) |
| 종료 | 오늘 `23:59:59.999` (로컬 시각) |

- 필터는 **구간 겹침** 기준이므로, 어제 시작해 오늘까지 이어지는 로그도 포함된다.
- 삭제된 로그는 제외된다.
- 정렬은 생성일 내림차순이다.

## 5. 기능 상세

| ID          | 기능                | 설명                                                                            |
| ----------- | ------------------- | ------------------------------------------------------------------------------- |
| FR-TODAY-01 | 오늘 로그 목록 조회 | 오늘 구간과 겹치는 로그를 조회한다.                                             |
| FR-TODAY-02 | 로그 생성           | `Add log` 버튼으로 빈 로그를 즉시 생성한다. 별도 입력 폼이나 다이얼로그가 없다. |
| FR-TODAY-03 | 뷰 전환             | 카드 뷰 ↔ 캘린더 뷰를 토글한다.                                                |
| FR-TODAY-04 | 로그 상세 열기      | 카드 또는 캘린더 블록을 클릭하면 우측 상세 패널이 열린다.                       |
| FR-TODAY-05 | 인라인 편집         | 카드에서 제목·설명·상태·시간·프로젝트·유형·태그를 직접 수정한다.                |
| FR-TODAY-06 | 로그 삭제           | 카드 우클릭 컨텍스트 메뉴 → `Delete` → 확인 다이얼로그.                         |
| FR-TODAY-07 | 빈 상태 안내        | 로그가 없으면 안내 문구를 표시한다.                                             |
| FR-TODAY-08 | 로딩 / 오류 상태    | 로딩 중 안내 문구, 오류 시 재시도 버튼을 제공한다.                              |

## 6. 화면 구성

```
┌─────────────────────────────────────────────────────────┐
│ Today's Log            [카드│캘린더]      [+ Add log]   │  ← ContentHeader
├─────────────────────────────────────────────────────────┤
│                                                         │
│  [카드 뷰]                    또는    [캘린더 뷰]        │
│  ┌───────────────────────┐           00 ─────────────   │
│  │ 상태  ·  시작–종료 시간│           01 ─────────────   │
│  │ [프로젝트][유형][세부] │           ...               │
│  │ 제목                   │           09 ┌──────────┐   │
│  │ 설명                   │              │ 로그 블록 │   │
│  │ [태그][태그]  2/5 used │           10 └──────────┘   │
│  └───────────────────────┘           ...               │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

### 6.1 뷰 전환 토글

| 값         | 아이콘           | 접근성 라벨     |
| ---------- | ---------------- | --------------- |
| `card`     | `list`           | `Card view`     |
| `calendar` | `calendar_today` | `Calendar view` |

기본값은 `card`이며, 선택 상태는 화면 로컬 상태로만 유지되어 화면을 벗어나면 초기화된다.

## 7. 상태별 표시

| 상태                              | 표시 내용                                                                                     |
| --------------------------------- | --------------------------------------------------------------------------------------------- |
| 로딩 중                           | `Loading tasks...` (`role="status"`, `aria-busy="true"`)                                      |
| 오류                              | 오류 코드에 대응하는 사용자 메시지 + `Retry` 버튼                                             |
| 로그 없음 (카드 뷰)               | `No tasks for today.` / `Let's add some logs to track your progress and reflect on your day!` |
| 시간 입력된 로그 없음 (캘린더 뷰) | `No time-tracked tasks for today. Add start & end times to see them here.`                    |

## 8. 비즈니스 규칙

| ID          | 규칙                                                                                                               |
| ----------- | ------------------------------------------------------------------------------------------------------------------ |
| BR-TODAY-01 | `Add log`은 입력값 없이 로그를 즉시 생성한다. 생성된 로그는 제목 `Untitled`, 상태 `todo`로 목록 최상단에 나타난다. |
| BR-TODAY-02 | 캘린더 뷰에는 **시작 시각과 종료 시각이 모두 있는** 로그만 표시된다.                                               |
| BR-TODAY-03 | 카드 클릭으로 상세 패널을 열 때, 클릭 지점이 입력·버튼·셀렉터 등 인터랙티브 요소이면 패널을 열지 않는다.           |
| BR-TODAY-04 | 목록 정렬 기준은 생성일 내림차순으로 고정되어 있으며 사용자가 변경할 수 없다.                                      |
| BR-TODAY-05 | 로그 생성 시 `task_created` 분석 이벤트를 전송한다.                                                                |

## 10. 현재 제한사항 및 향후 계획

- 페이지뷰 분석 이벤트 전송이 코드에 TODO 주석 상태로 비활성화되어 있다.
- 뷰 모드(카드/캘린더) 선택이 저장되지 않아 화면을 벗어나면 초기화된다.
- 날짜를 이동해 어제·특정 날짜의 로그를 보는 기능이 없다(주간 요약 화면에서만 주 단위 이동 가능).
- 검색·필터 UI가 없다.
- 로그 목록을 사용자가 정렬하거나 그룹핑할 수 없다.
